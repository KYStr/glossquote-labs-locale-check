格式與限制

根節點必須是物件，葉節點只能是字串。空物件合法；只比較字串葉，不將空物件當成字串。每份最多 32 層物件（根計 1）、10,000 個屬性；每個 key 最多 200、每個字串最多 16,384 個 UTF-16 code units。重複 key（含解碼後重複）、危險 key、未配對 surrogate、陣列、null、數字與布林值會拒絕整份輸入。

路徑以獨立分段識別，例如 ["a.b"] 與 ["a","b"] 不相同。字串與物件衝突時只列父路徑，其子樹不重複列缺漏／多餘。數字型 key 依原始輸入順序保留。

使用裝置記憶體處理；超過限制會停止。清除僅清本頁資料與下載連結，不會刪除已下載檔案，也不承諾安全抹除瀏覽器或系統記憶體。

常見問題

這能判斷翻譯品質嗎？

不能；它核對欄位、字串與明確支援的插值變數，不判斷語意。

支援 ICU 嗎？

首版不支援 ICU；不認識的括號語法列為待人工確認。%s 不屬於本工具的變數語法。

同原文代表漏翻嗎？

不一定，品牌名與數字可能應保留；只提供提醒。空譯文也只列提醒，請依情境判斷。
