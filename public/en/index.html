Format and limits

The root must be an object and leaves must be strings. Empty objects are valid; only string leaves are compared, so empty objects are not treated as strings. Each input: 32 object levels (root = 1), 10,000 properties, 200 UTF-16 code units per key and 16,384 per string. Duplicate decoded keys, unsafe keys, unpaired surrogates, arrays, null, numbers and booleans reject the entire input.

Paths use independent segments: ["a.b"] differs from ["a","b"]. A string/object conflict is listed at the parent path; descendant missing/extra keys are suppressed. Numeric-looking keys keep their original input order.

Processing uses device memory and stops at the limits. Clear removes this page’s data and download links, not files already downloaded. It does not promise secure erasure of browser or system memory.

Frequently asked questions

Does this assess translation quality?

No. It checks keys and supported placeholder syntax, not linguistic quality.

Is ICU supported?

No. Unsupported brace syntax is flagged for review. %s is not a supported placeholder syntax.

Is unchanged text an error?

No. Names and numbers may intentionally match; this is a review warning. Empty translations are also warnings for you to assess in context.
